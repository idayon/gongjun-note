# 다차원 전형 및 PT 대비 양식

> 인수인계 문서 · 2026-11-15 작성
> 사용자가 "이 모양새로 나중에 써먹자"고 정한 **모의 과제(예비 문제) 양식**이다.
> 앞으로 다차원 전형, PT 면접, 주제 작성, 인바스켓 대비 요청이 오면 이 양식으로 만든다.

- 참고 구현(완성본): `templates/mock-template.html`
- 원본·실사용 페이지: https://idayon.github.io/nrf-interview-prep/mock1.html (저장소 `Desktop\nrf-interview-prep`)
- 사용자가 확정한 요구: ① **과제는 맨 위 고정** ② **자료는 번호 탭(1, 2, 3…)으로 한 장씩 넘김** ③ **답안은 코넬식 노트처럼 세로로 쪼갠 칸**

## 1. 화면 구성 (바꾸지 말 것)

```
┌──────────────────────────────────────────────────┐
│ 제목 · ⏱ 타이머 [시작][멈춤][처음으로] · ← 돌아가기  │
│ [과제] ① … ② … ③ … ④ … ⑤ …  · 시간 · 분량          │  ← 상단 고정 (head)
├───────────────────────┬──────────────────────────┤
│ [1][2][3][4][5][6][7] │ 단서 칸      │ 답 칸       │
│                       │ ① 항목 이름  │ textarea    │
│  자료 한 장 (doc.on)   │   힌트·글자수│             │
│                       │ ② …          │             │
│                       │ …            │             │
│ ◀ 이전  4/7  다음 ▶   │ 결론(요약)   │             │  ← 코넬식 (cue | notes, 맨 아래 summary)
└───────────────────────┴──────────────────────────┘
```

- PC: 좌우 분할 (`.split` grid, 자료 1 : 답안 1.15)
- 폰(≤800px): 위 자료 45% / 아래 답안 55%, 단서 칸은 96px로 줄이고 힌트 숨김
- 자료 넘기기: 번호 탭, 이전/다음 버튼, **Alt + ← / →** (글 쓰는 중에도 넘길 수 있게)
- 타이머: 5분 남으면 주황, 끝나면 빨강 + 진동
- 답안: 칸마다 localStorage 자동 저장(문제마다 키를 다르게, 예 `nrf-mock1c`), 칸별·전체 글자 수(공백 포함/제외)
- **답안 전체 복사**: `결론 → ① → ⑤` 순서로 `[항목 이름]` 머리를 붙여 합친다 → 사용자가 Claude에게 붙여넣어 채점받음
- 색·폰트·다크모드 토큰은 참고 구현의 `:root` 그대로 사용

## 2. 문제(자료 묶음) 만드는 규칙

실제 공공기관 다차원·역량평가·PT처럼 **A4 여러 장짜리 자료 묶음**을 준다. 한 문장짜리 참고자료는 사용자가 "시험장처럼 아니다"라고 지적했음.

**자료 7장 안팎, 종류를 섞는다**
| 번호 | 종류 | 역할 |
|---|---|---|
| 1 | 상사 지시 메일 | 과제 범위·**제약(예산, 인력, 기한)**·이해관계자 우려 |
| 2 | 내부 현황 표 | 업무별 건수·처리시간·의견 → 우선순위 판단 근거 |
| 3 | 설문·민원 | 이해관계자 찬반 수치 + 자유 의견 |
| 4 | 언론 기사 요약 | 실제 최근 이슈(사실만) |
| 5 | 다른 기관 사례 | 실패 사례 1 + 성공 사례 1 (대비되게) |
| 6 | 예산 견적 | **조합해야 상한에 맞는** 선택지 |
| 7 | 규정·원칙 발췌 | 넘으면 안 되는 선 (함정 판별 근거) |

**반드시 넣을 장치**
- **함정 1개**: 효과는 커 보이지만 규정·이해관계자 반대로 고르면 안 되는 선택지 (예: AI가 평가 점수 산정)
- **충돌 자료**: 같은 대상에 대해 장점·위험이 다른 자료에 나뉘어 있게
- **예산 조합**: 항목을 다 합치면 상한 초과 → 골라 담아야 하게
- 과제 항목은 5개 안팎: 대상·이유 / 운영 방법 / 위험·대책 / 예산 / 지표·확대 조건 (PT면 "발표 3~5분 구성"으로 바꿈)

**사실과 가상 구분 (필수)**
- 실제 기관 사실(사업명, 위원회, 국감 지적 등)은 확인된 것만 쓴다.
- 표·설문·사례·예산 숫자는 **가상 수치**로 만들고, 화면 맨 위에 **"연습용 자료 · 가상 수치 · 시험장에서 인용 금지"** 경고를 둔다.

## 3. 유형별 변형

| 유형 | 시간·분량 | 코넬 단서 칸 |
|---|---|---|
| 주제 작성(보고서) | 30~40분 · 1,000~1,500자 | ①~⑤ 과제 항목 + 결론 |
| PT 발표 | 준비 30분 + 발표 5분 | 결론 한 문장 / 현황·문제(수치) / 원인 / 개선안 3개(단기·중기) / 기대효과·한계 / 예상 꼬리질문 |
| 집단토론 | 준비 10분 + 발언 40초 단위 | 내 입장 / 근거 2개 / 상대 예상 논거 / 합의안 / 마무리 정리 멘트 |
| 인바스켓 | 40~60분 | 우선순위 표 / 처리 방법 / 위임·보고 대상 / 근거 자료 번호 |

## 4. 채점 기준 (사용자가 답안을 붙여넣으면)

| 항목 | 배점 |
|---|---|
| 구조 (결론 먼저, 흐름, 마무리) | 20 |
| 자료 활용 (근거 자료 번호 2개 이상, 함정 회피) | 20 |
| 위험 인식 (공정성·보안·책임) | 20 |
| 방안 현실성 (단계·주체·지표·예산 합계) | 25 |
| 기관 관점 (이해관계자는 고객, 공정·투명, 결정권자 구분) | 15 |

채점 후에는 **꼭 고칠 3~5가지 + 고쳐 쓴 예시 문단 1개 + 띄어쓰기·오타**를 준다. 사용자 경험 소재(경력_입력용.md의 확인된 사실)를 끼워 넣을 자리를 짚어 준다.

## 5. 공준노트에 넣을 때 (나중 일)

- 지금은 문제 1개 = HTML 1장. 공준노트에 넣을 때는 **자료·과제·코넬 칸을 JSON으로 분리**하고 한 템플릿이 읽게 만든다. 예:
  ```json
  {"id":"nrf-ai-pilot","title":"연구관리 AI 시범사업","type":"report","minutes":40,"length":"1,000~1,500자",
   "task":["대상 업무와 선정 이유","운영 방법","위험과 대책","예산 배분 (3억 원 이내)","성과 지표와 확대 조건"],
   "docs":[{"no":1,"title":"상사 지시 메일","html":"…"}],
   "cues":[{"key":"q1","label":"① 대상 업무·선정 이유","hint":"어떤 업무? 왜? (자료 근거)"}],
   "traps":["과제 선정 점수 산정 — 평가위원 권한, 연구자 반대 78%"],
   "model":"모범 답안 개요(채점용, 화면 비공개)"}
  ```
- 메뉴 위치 후보: 공부 › **면접·다차원**. 무료 1문제 + 나머지 유료 후보.
- 기관별 실제 사실은 시간이 지나면 낡으므로 문제마다 `asOf`(기준일)를 넣는다.
